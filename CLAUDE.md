# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

Одна статическая страница на русском: сравнение стоимости открытия и содержания торговой компании (мясо и корма из России, опт в стране) в Гонконге, Бахрейне, Маниле, Сингапуре, Дубае и Абу-Даби, плюс виза для жизни основателя (расчёт на 1.11.2026, курс ЦБ на 31.10). Суммы считаются по схеме А — трейдер без своего склада; склад, пошлины и сборы за партии в расчёт не входят. Сборки, зависимостей, линтера и тестов нет.

- `index.html` — вся страница: CSS и разметка в одном файле, снаружи грузятся только шрифты Google Fonts. Открывается двойным щелчком, сервер не нужен.
- `entity-budget.pdf` — A4-версия для пересылки, **генерируется** из `index.html`, вручную не правится.
- Публикация: GitHub Pages из корня ветки `main` репозитория `DaniilGlushko/entity-budget-asia` → https://daniilglushko.github.io/entity-budget-asia/ (PDF лежит рядом по `/entity-budget.pdf`). Push в `main` = выкладка.

## Инструменты: скилл `jurisdiction-budget`

Страница собрана скиллом `~/.claude/skills/jurisdiction-budget` (его `SKILL.md` — основная инструкция по добавлению стран и обновлению цифр). Скрипты:

```bash
# пересчитать месяц / старт / первый год и ширины полос (формат JSON — в начале calc.py)
python3 ~/.claude/skills/jurisdiction-budget/scripts/calc.py budget.json

# собрать самодостаточный index.html из черновика
python3 ~/.claude/skills/jurisdiction-budget/scripts/standalone.py page.html index.html

# перегенерировать PDF (headless Chrome; --keep-html print.html для отладки вёрстки печати)
python3 ~/.claude/skills/jurisdiction-budget/scripts/make_pdf.py index.html entity-budget.pdf --url https://daniilglushko.github.io/entity-budget-asia/
```

После любой правки `index.html` перегенерируйте PDF и коммитьте оба файла вместе, иначе ссылка «PDF для пересылки» разойдётся со страницей.

## Как устроена страница

Порядок секций (комментарий в начале `<style>`): шапка с допущениями → «Две схемы торговли» (`section.models`) → карточки-итоги → полосы «Из чего складывается месяц» → подробная таблица → риски → источники.

**Одна и та же цифра живёт в нескольких местах.** Меняя сумму по стране, обновите все:
- карточку (`.card`: «В месяц», Старт, Первый год, Регистрация, Мин. капитал, «Мясо из РФ», чипы офиса и визы);
- полосу (`.bar-row`: `width:%` у каждого `<i>`, `aria-label` с суммами и `.total`);
- строки таблицы, включая группу «Итог»;
- чипы курсов и зарплаты в местной валюте в шапке (`.assume`).

Добавляя или убирая страну, обновите ещё `<h1>`, `<title>`, список стран в `README.md` и `colspan` в строках-группах таблицы (сейчас `7`).

**Формулы** (так же расписаны под таблицей; считать через `calc.py`, чтобы все страны шли по одному правилу):
- месяц = зарплата + взносы работодателя + аренда + офис/адрес + годовое обслуживание / 12;
- старт = разовые расходы + возвратные депозиты + минимальный капитал + 3 месяца расходов вперёд + аренда, оплаченная сверх этих 3 месяцев (чеки в ОАЭ);
- первый год = разовые расходы + 12 месяцев, депозиты не включаются.

В конце `<style>` есть блок `@media print`: в PDF он ставит карточки сразу после шапки, а «Две схемы торговли» — после них (иначе первая страница остаётся полупустой). Секцию схем нельзя делать `<section class="notes">`: `make_pdf.py` переносит первую такую секцию (риски) под график.

Ширины полос считаются на **общей шкале** для всех стран. Если меняется самая дорогая страна, меняются ширины у всех строк: берите их из `calc.py`, не подбирайте вручную.

## Соглашения по содержанию

- Пишем по-русски, коротко. Каждая сумма: местная валюта и «≈ … ₽».
- Чипы: `ok` = хватает адреса / нормы нет, `warn` = flexi-desk, коммерческий адрес или «уточнить», `crit` = реальный офис или жёсткое условие.
- Если источники расходятся, показываем оба значения с чипом «уточнить» и не выбираем одно; если данных нет, пишем «уточнить». Капитал WLL в Бахрейне уже решён: минимума нет (закон 50/2014), не возвращайте старые BHD 20 000.
- Если у двух городов одной страны общие правила, ячейки объединяются через `colspan` (Дубай + Абу-Даби). Такие города делят одну карточку `card wide`; сетка карточек в 3 колонки, ряды должны заполняться.
- В рисках первым всегда идёт «Банк и платежи российским поставщикам». Каждую новую цифру подкрепляем ссылкой в `footer.src`.
- Цвета заданы токенами в трёх местах: в `:root`, в `@media (prefers-color-scheme: dark)` и в `:root[data-theme="dark"]`. Меняя токен, меняйте все три.
